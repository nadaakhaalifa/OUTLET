## 1. Description of the processing

- Generates 3 to 5 complete outfits from occasion, vibe, season, modesty level and budget, mixed across stores, in the user size and in stock.
- Components: item attribute extraction (vision plus LLM), image embeddings, a per-user style vector updated online from like, dislike and swap, and a constrained optimiser. Phase 3 adds chat.
- Fallback when ML is down: rule-based templates. Outputs are catalog product ids validated server-side. Prices are never generated by the model.

## 2. Data and data subjects

- **Data subjects:** Adult shoppers. Wardrobe photos may show other people or interiors.
- **Inventory tables:** `product_attributes`, `product_embeddings`, `outfits`, `stylist_feedback`, `style_profiles`, `wardrobe_items`, `outfit_calendar_events`, `llm_audit_log`, `llm_external_calls` (field-level tags are in [ropa.md](ropa.md))

- **Recipients and processors:** see [processors-register.md](processors-register.md). All DPA statuses are unknown.

## 4. Risks and mitigations

Likelihood, severity and residual risk are intentionally blank.

| # | Risk to individuals | Mitigation in the design | Likelihood | Severity | Residual |
|---|---|---|---|---|---|
| 1 | Profiling of style, body shape or religion inferred from modesty preferences | Modesty level is an explicit user input; inferred attributes of sensitive categories are not stored. Review whether the modesty flag is special-category data under the PDPL (VERIFY). | | | |
| 2 | P2/P3 leakage to an external LLM vendor | Spec T12 LLM02: size passed as a label, no raw measurements, PII scrubber, field allow-list in llm-gateway, audit by prompt hash. Inventory enforces external_llm never for P3. | | | |
| 3 | Wardrobe photos exposing third parties or location metadata | Images are P2 and user-deletable; EXIF stripping on upload; no use for training without a separate consent (to be defined). | | | |

| 5 | Opaque recommendations and filter-bubble effects | UI states "AI suggestions" (LLM09); explanations shown; user can reset the style vector (to be built, see open items). | | | |
