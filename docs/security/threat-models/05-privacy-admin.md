# Threat model 05: privacy (PDPL) and admin console

Status: Draft for review · Date: 2026-10-11 · ASVS level: L3 for admin · Spec refs: §2, §B1, §23, §T5 · Code: `apps/api/src/modules/{privacy,admin}`, `apps/admin-web`, `packages/privacy`, `packages/feature-flags` · Older detail: `privacy-and-consent.md`, `admin-and-audit.md`.

## Trust boundaries
Shopper to Privacy Center APIs; DPO/admin staff (passkey session) to `/admin/*`; worker that builds export ZIPs and runs erasure; flag provider; audit sink.

## Residual risk
In-memory flag provider means a restart reverts flags to default-off (fail closed, but also a payment outage after deploy). Admin-web CSP, IP allow-list for Finance (spec §23) not implemented. No DPIA or TIA documents verified in this pass (VERIFY `docs/privacy`).
